# Кредит без переплат

Русскоязычный сервис для финансовых решений: показывает, сколько человек заплатит по ипотеке, автокредиту или крупной покупке на самом деле, где возникает переплата и как заплатить меньше с учётом бюджета и резерва.

Все суммы считают алгоритмы (точная десятичная арифметика), текст разбора собирается из уже посчитанных значений. Внешние ИИ-сервисы и платные API не используются.

## Что реализовано (MVP)

| Раздел | Адрес | Что умеет |
|---|---|---|
| Ипотека | `/ipoteka` | Аннуитет и дифференцированные платежи; проценты по дням (365/366) или ставка/12; страховки (% от остатка в год + фикс), разовые и ежемесячные комиссии; полная стоимость покупки, переплата, оценка ПСК; досрочные платежи — разовые, ежемесячные, ежегодные, несколько сразу, с уменьшением срока или платежа; график, остаток долга на дату, выгрузка CSV; таблица «срок → платёж → переплата»; подбор лучшего сценария под бюджет, резерв и доход; финансовый разбор |
| Сравнение предложений | `/sravnenie-kreditov` | 2–6 предложений: ставка, страховки, комиссии, доп. услуги (в т. ч. включённые в кредит), условия досрочки; рейтинг по переплате (одинаковые сумма и срок) или по ПСК |
| Рефинансирование | `/refinansirovanie` | Выгода с учётом расходов на переход и страховок, срок окупаемости |
| Автомобиль | `/avtokredit` | Стоимость владения в месяц / год / за период: кредит, КАСКО, ОСАГО, ТО, ремонт, топливо, налог, потеря стоимости, долг при продаже; сравнение: с доп. услугами и без, наличные, авто с пробегом, разные сроки; «в сегодняшних деньгах» |
| Крупные покупки | `/krupnye-pokupki` | Сразу / кредит / рассрочка / накопить; эффективная ставка «беспроцентной» рассрочки; рост цены и доходность вклада |
| Кредитные карты | `/kreditnye-karty` | Каталог 11 карт с «рекламным» и реальным льготным периодом и ловушками (платные продления, ежедневные платы, акции); расчёт долга: в льготный период, фиксированным платежом, только минимальным платежом; снятие наличных с комиссией |
| Методика, О проекте, API | `/metodika`, `/o-proekte`, `/api-docs` | Формулы и допущения, правила рекламы, документация API |
| SEO | — | SSG всех страниц, Schema.org (WebApplication, BreadcrumbList, FAQPage, WebSite), `sitemap.xml`, `robots.txt`, `llms.txt`, ЧПУ, canonical |

Светлая и тёмная темы (без вспышки при загрузке), mobile first, регистрация не нужна, расчёт идёт в браузере.

## Запуск локально

Нужны Node.js 24 и pnpm.

```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm test           # тесты финансовых формул (vitest)
pnpm lint
pnpm build && pnpm start
```

## Docker (VPS Ubuntu 24.04)

Отдельный контейнер, слушает только `127.0.0.1:3210`, ничего не меняет в других сервисах. Тесты формул выполняются при сборке образа — с ошибкой в расчётах образ не соберётся.

```bash
docker compose build
docker compose up -d
curl http://127.0.0.1:3210/api/health
```

Переменные сборки (через `.env` рядом с `docker-compose.yml` или окружение):

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `SITE_URL` | `http://localhost:3210` | Адрес сайта для canonical, sitemap, Schema.org |
| `INDEXING` | `off` | `on` — открыть индексацию в `robots.txt`. До согласования домена — закрыто |
| `PARTNERS` | `off` | `on` — показать рекламные слоты (помечены «Реклама», на расчёт не влияют) |

Публикация на домене — через reverse proxy (nginx/Caddy) только после согласования владельцем.

## API

`POST /api/v1/{mortgage|compare|refinance|car|purchase}`, тело — JSON, ответ — `{ result, disclaimer }`. Ошибки входа — 422 со списком полей. Схемы — `src/lib/api/schemas.ts`, примеры — `/api-docs`.

## Структура


## Условия банков

`src/data/bank-offers.ts` — каталог условий с официальных сайтов банков (ВТБ, Т-Банк, Банк ДОМ.РФ, ПСБ, Альфа-Банк, Газпромбанк, Сбербанк, WB Банк): ставка и ПСК «от–до», лимиты, надбавки и скидки, ссылка на источник, дата проверки. Если банк не публикует ставку на странице продукта, поле пустое: цифры агрегаторов не используются. Ozon Банк и Совкомбанк не вошли — их сайты не отдали страницы с условиями.

Каталог используется в подборе на `/sravnenie-kreditov` (лучший и худший случай по опубликованным ставкам, порядок — по минимальной ПСК) и в подсказках ставок в калькуляторах ипотеки и автомобиля. Везде рядом показывается предупреждение: данные могут быть неточными, подбор ориентировочный, точные условия — в банке.

`src/data/credit-cards.ts` — условия кредитных карт с banki.ru, `src/data/glossary.ts` — справки к значкам «?», `src/data/dealer-services.ts` — услуги автосалона с пояснениями.

Обновление: открыть `sourceUrl`, сверить цифры, поменять их и `checkedAt`. Тест проверяет, что у каждой записи есть источник, дата и корректные диапазоны. Условия меняются часто — проверять хотя бы раз в месяц.

## Допущения

- Досрочный платёж вносится в дату планового платежа.
- Страховка — раз в год от остатка долга на начало года кредита.
- ПСК — оценка по формуле ч. 2 ст. 6 353-ФЗ по введённым данным; официальное значение — в договоре.
- Значения в полях по умолчанию — демонстрационные, не рыночные ставки.

## Следующие этапы

1. Ссылка на расчёт (параметры в URL) и сохранение сценариев.
2. Налоговый вычет (имущественный и по процентам) в полной стоимости покупки.
3. Досрочные платежи в произвольную дату, кредитные каникулы, изменение ставки (льготный период, плавающая ставка).
4. Отдельные страницы-гайды с реальной пользой (не автогенерация): «досрочка: срок или платёж», «как читать договор и ПСК».
5. Платный расширенный отчёт (PDF с графиком и разбором), партнёрские блоки — после согласования.
6. Проверенные источники ставок (например, данные Банка России) — только с указанием источника и даты.
